│  ├─ auth/         better-auth setup

│  └─ config/       shared tsconfig

## Rules

- `apps/api` is the only app that touches the database, auth and providers. `web` and `dashboard` call it through `@acme/orpc`, so secrets and data access live in one place
- anything used by more than one app or package goes in `@acme/common`: schemas and their types, constants, small utils. Don't redeclare a type in an app when one exists there
- the theme lives in `packages/ui/src/styles/theme.css`, use its tokens instead of raw colors
- the database schema is in `packages/db/src/schema`, change it and run `pnpm db:generate` to get a migration, never write one by hand

## Adding an endpoint

1. put the input and output schemas in `packages/common/src/schemas`
2. add the procedure in `packages/orpc/src/routers`
3. call it from an app with `orpc.<router>.<procedure>` in client components or `call((api) => ...)` on the server
