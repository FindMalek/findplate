Acme is a turborepo with a landing page, a dashboard with login, and an api, wired to postgres, auth and typed rpc. These pages describe the project as it was generated. Edit them in `apps/docs/content/docs`, they are plain mdx.

## What is in the repo

- `apps/web`: the landing page. It only talks to the api
- `apps/dashboard`: login and the app shell. It only talks to the api
- `apps/api`: orpc on bun. The only app that touches the database, auth and providers
- `apps/docs`: this site
- `packages/*`: shared code, see [structure](/docs/structure)
