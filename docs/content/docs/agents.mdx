## Rules with ruler

The plan is one source in `.ruler/`, and [ruler](https://github.com/intellectronica/ruler) generating the rules each agent reads:

- Claude Code
- Cursor
- opencode
- Zed
- oh-my-pi

MCP servers and skills are installed through the skills cli, so a new teammate or a fresh agent session starts with the same context.

## Skills

Per-project skills for the workflow around a ticket: dive into it, plan it, ship it ([#17](https://github.com/FindMalek/findplate/issues/17)).

## Today

Agents can already drive the generator itself with no prompts, see [agent mode](/docs/cli#agent-mode). The Next apps also carry an `AGENTS.md` that points agents to the bundled Next docs.
