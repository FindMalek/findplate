## In the findplate repo

Every pull request runs:

- `repo`: biome, the cli type check and tests, and syncpack on the template.
- one `template` job per module, plus `all modules` and `minimum`. Each generates a project, then runs lint, types and tests. The two aggregate jobs also build.
- `migrations`: generates the drizzle migration in a generated project and fails if it drifts.
- `lighthouse`: audits the generated landing page.
- PR hygiene: no AI attribution, a `closes #n` link, and `type(scope): subject` commits.

The module jobs are built at runtime from `template/findplate.json`, so a new module needs no CI edit.

## In a generated project

The project ships `ci`, `pr-hygiene` and `project-status` workflows, issue and PR templates, and the [Dokploy preview](/docs/previews) workflows. `findplate github` wires the repo variables and the board, see [GitHub](/docs/github).

## Run the checks yourself

```bash
pnpm lint
pnpm check-types
pnpm test
pnpm build
```
