## Requirements

- Node 24 or newer for the generated project (the cli itself runs on Node 20.19 or newer)
- Linux, macOS or Windows, see [supported platforms](/docs/cli#supported-platforms), WSL is recommended on Windows
- [pnpm](https://pnpm.io) for the generated project
- Docker, for the local Postgres
- [bun](https://bun.sh), if you run the cli with `bunx`

## Create a project

<Tabs groupId="pm" persist items={["bun", "pnpm", "npm", "yarn"]}>
  <Tab value="bun">

```bash
bunx findplate create
```

  </Tab>
  <Tab value="pnpm">

```bash
pnpm dlx findplate create
```

  </Tab>
  <Tab value="npm">

```bash
npx findplate create
```

  </Tab>
  <Tab value="yarn">

```bash
yarn dlx findplate create
```

  </Tab>
</Tabs>

The prompts ask for a project name, a one-line pitch, a design preset and the modules to include. Every answer has a flag, see the [CLI reference](/docs/cli).

The cli then copies the template, installs dependencies, formats the result with biome and makes the first git commit on `main`.

## Run it

```bash
cd my-app
pnpm db:up
pnpm dev
```

| App | URL |
| --- | --- |
| web | http://localhost:3000 |
| api | http://localhost:3001 |
| dashboard | http://localhost:3002 |

`pnpm db:up` starts Postgres in docker, on the first free port from 5432. The dashboard admin email is printed when the cli finishes, and the password is `ADMIN_PASSWORD` in your `.env`.
