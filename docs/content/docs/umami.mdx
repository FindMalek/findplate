---
title: Umami
description: Self-hosted web analytics script.
---

The `umami` module loads the [Umami](https://umami.is) script in `apps/web` and `apps/dashboard`. It is off by default.

```bash
findplate create my-app --modules umami
```

## What it adds

Files and folders:

- `apps/web/components/umami.tsx`
- `apps/dashboard/components/umami.tsx`

## Env keys

```bash
NEXT_PUBLIC_UMAMI_URL=
NEXT_PUBLIC_UMAMI_WEBSITE_ID=
```

Both keys are inlined at `next build`, so pass them as build args on Docker and Dokploy. With the website id empty nothing is tracked. A compose file for the server is in [self-hosted tools](/docs/self-hosted#umami).

## Remove

Generate without it: leave `umami` out of `--modules`. In a project that already exists, delete the paths above, drop its packages from the `package.json` files, remove its env block and fix what `pnpm check-types` reports.

## Swap

Analytics modules are independent. Generate with `databuddy` instead for cookieless tracking, or keep both. See [Databuddy](/docs/databuddy).
