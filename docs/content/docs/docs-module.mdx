The `docs` module adds `apps/docs`, a Next app on port 3003 that uses your preset's tokens and fonts. It is on by default.

```bash
findplate create my-app --modules docs
```

## What it adds

Files and folders:

- `apps/docs`

Packages:

- `fumadocs-core`
- `fumadocs-mdx`
- `fumadocs-ui`
- `@types/mdx`

## Env keys

```bash
DOCS_URL=http://localhost:3003
```

The pages are mdx in `apps/docs/content/docs`: setup, environment, structure, scripts and deploy, written for the generated project. Edit them like any other file. It has its own `Dockerfile`.

## Remove

Run `findplate remove docs` in the project, see [add and doctor](/docs/add-doctor#findplate-remove). It deletes the files the module owns, strips its code from shared files and drops its packages, only where you haven't edited them.

If you'd rather do it by hand: for a new project leave `docs` out of `--modules`. In a project that already exists, delete the paths above, drop its packages from the `package.json` files, remove its env block and fix what `pnpm check-types` reports.

## Swap

The content is plain mdx with fumadocs, so move it to any docs tool that reads mdx.
