---
title: Modules
description: Optional packages the cli switches on or off.
---

A module is a package plus the code and env keys that depend on it. Turn one off and the cli deletes its package, its env block and every line between the `@findplate:<module>` and `@end` markers in the template.

Select modules with `--modules storage,ai,docs,email`, or in the prompt.

## Available

Each module has a page with what it adds, its env keys, how to remove it and how to swap it.

| Module | Default | What it adds |
| --- | --- | --- |
| [`storage`](/docs/storage) | on | `packages/storage`. Uploads to any S3 API: Garage, R2, AWS, MinIO |
| [`ai`](/docs/ai) | on | `packages/ai`. Vercel AI SDK with Groq, OpenAI or Anthropic |
| [`umami`](/docs/umami) | off | umami script in web and dashboard |
| [`openobserve`](/docs/openobserve) | off | otel traces from the api to OpenObserve |
| [`glitchtip`](/docs/glitchtip) | off | sentry sdk in api, web and dashboard, pointed at GlitchTip |
| [`infisical`](/docs/infisical) | off | `pnpm dev:secrets` runs dev with infisical |
| [`langfuse`](/docs/langfuse) | off | Langfuse traces for AI SDK calls (needs `ai`) |
| [`waitlist`](/docs/waitlist) | off | email signup on the landing page, signups listed in the dashboard |
| [`roadmap`](/docs/roadmap) | off | public `/roadmap` from the repo's GitHub milestones |
| [`status`](/docs/status) | off | public `/status` with live checks of api, database, web and dashboard |
| [`databuddy`](/docs/databuddy) | off | cookieless analytics in web and dashboard |
| [`whatsapp`](/docs/whatsapp) | off | `packages/whatsapp`. `notify()` through Kapso template messages. |
| [`telegram`](/docs/telegram) | off | `packages/telegram`. Bot with `notify()`, a webhook route and a setup command. |
| [`webhooks`](/docs/webhooks) | off | `packages/webhooks`. Signature checks for inbound webhooks: hmac, svix, secret header. |
| [`rate-limit`](/docs/rate-limiting) | on | per route and ip limits on the api, in memory or on Upstash Redis. |
| [`logger`](/docs/logger) | off | `packages/logger`. Json logs with request ids and redaction in api, web and dashboard. |
| [`docs`](/docs/docs-module) | on | `apps/docs`. A fumadocs site on Next with pages about your project |
| [`email`](/docs/email) | off | `packages/email`. react-email templates sent through email-sdk and Resend. |

## Dependencies between modules

`langfuse` requires `ai`, and `telegram` requires `webhooks`. The cli turns required modules on for you, so `--modules langfuse` generates `ai,langfuse`.

The self-hosted ones (umami, openobserve, glitchtip, infisical, langfuse) also have a compose snippet each in [self-hosted tools](/docs/self-hosted).
