---
title: Modules
description: Optional packages the cli switches on or off, grouped, with the profiles that pick them.
---

A module is a package plus the code and env keys that depend on it. Turn one off and the cli deletes its package, its env block and every line between the `@findplate:<module>` and `@end` markers in the template.

Everything that is not a module is the [core](/docs/project-structure#core-and-modules), and is always generated.

Pick a profile with `--profile minimal|standard|everything`, list exact modules with `--modules storage,ai,docs,email`, or choose in the prompt. `--modules` wins over `--profile`.

## Profiles

| Profile | Picks |
| --- | --- |
| `minimal` | no modules, just the core. Add some later with `findplate add` |
| `standard` | `storage`, `ai`, `docs`, `rate-limit`. The default with `-y` |
| `everything` | every module that runs without a server of your own |

`everything` leaves out `umami`, `openobserve`, `glitchtip`, `infisical` and `langfuse`. They only work once you host the matching server, so switching them on by default would hand you code that does nothing. Add them one by one with `--modules` or in the checklist when you run the server.

## What each module needs from you

The cli lists this before it asks for keys, and `findplate doctor` warns about any key still empty in `.env`, with the page to get it from. Every key is optional at creation time.

| Module | Needs |
| --- | --- |
| `ai` | one of [Groq](https://console.groq.com/keys), [OpenAI](https://platform.openai.com/api-keys) or [Anthropic](https://console.anthropic.com/settings/keys) |
| `notification` | any of a [Resend API key](https://resend.com/api-keys), a bot token from [@BotFather](https://t.me/BotFather) and a [Kapso API key](https://app.kapso.ai); each channel turns on with its keys |
| `databuddy` | a [Databuddy client id](https://app.databuddy.cc) |
| `umami`, `glitchtip`, `langfuse` | a self-hosted server, plus a website id, DSN or key pair from it |
| `openobserve`, `infisical` | a self-hosted server |

## Dependencies between modules

`langfuse` requires `ai`, and `notification` requires `webhooks`. The cli turns required modules on for you and says so in the prompt, so `--modules langfuse` generates `ai,langfuse`.

The self-hosted ones also have a compose snippet each in [self-hosted tools](/docs/self-hosted).
