findplate is a generator. One command creates a working turborepo with a landing page, a dashboard with login, and an api, wired to a database, auth and typed rpc. You pick a design preset and the optional modules you want, and you get a project you own from the first commit.

```bash
bunx findplate create
```

## What you get

- `apps/web`: a hero landing page, only talks to the api
- `apps/dashboard`: better-auth login and an app shell, only talks to the api
- `apps/api`: orpc on bun. The only app that touches the database, auth, storage and providers
- `packages/*`: `ui` (shadcn), `orpc`, `db` (drizzle and a seed scenario), `auth`, `env`, plus the optional modules
- biome for format and lint, oxlint for `@shadcn/lint`, security headers, one root `.env`
